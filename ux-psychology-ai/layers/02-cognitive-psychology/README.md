# Layer 02 — Cognitive Psychology

**Purpose:** Explain how the human mind processes, stores, and retrieves information when interacting with interfaces — and what limits that processing.

---

## Scope

This layer covers:
- Working memory and its limitations
- Cognitive load and its sources
- Chunking as an organizational strategy
- Recognition vs. recall as interaction modes
- Progressive disclosure for managing complexity
- Mental models and user expectations
- Cognitive friction as a design failure mode

**What is not in this layer:**
- How users perceive structure visually → Layer 01
- How users make decisions → Layer 03
- How users direct attention → Layer 04

---

## Core Question

> **What does this interface require from the human mind?**

Not: "Does it look simple?" — a visually minimal interface can still impose high cognitive load.

Not: "Does it have fewer items?" — fewer items without meaningful organization does not reduce cognitive effort.

The correct question is always about mental work: interpretation, comparison, recall, transformation, and decision.

## Scientific Qualification

Several principles in this layer are frequently oversimplified in UX practice.

**Miller's "7±2":** George A. Miller's 1956 paper described a limit on the span of immediate memory, not a rule for menu design. Modern cognitive science suggests working memory capacity is closer to 3–4 chunks for complex information. Do not encode "use 7 items" as a design rule. The accurate principle is chunking — grouping meaningful units.

**Cognitive Load Theory:** Developed by Sweller (1988) in educational psychology. Its three-type framework (intrinsic, extraneous, germane) is theoretically useful but not directly measurable in interface design contexts. Apply the framework conceptually, not as a measurement system.
