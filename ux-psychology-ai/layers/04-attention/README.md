# Layer 04 — Attention

**Purpose:** Explain how interfaces capture, direct, and maintain human attention, and the consequences when attention is mismanaged.

---

## Scope

Attention governs what is actually processed from the available interface. Perception (Layer 01) defines what can potentially be seen; attention determines what is actually noticed. Understanding attention allows designers to direct users to the right content at the right time — and to avoid inadvertently disrupting task focus.

This layer covers:
- Selective and focused attention
- Pre-attentive visual features
- Attentional capture (voluntary and involuntary)
- Change blindness and its interface implications
- Information scent for navigation
- Visual scanning patterns
- Attention management in dynamic interfaces

**What is not in this layer:**
- The perceptual grouping that attention acts upon → Layer 01
- Cognitive processing of attended content → Layer 02
- Decision-making with attended choices → Layer 03
