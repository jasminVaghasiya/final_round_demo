# Layer 05 — Interaction and Usability

**Purpose:** Explain how humans physically and cognitively interact with interface controls, and how to design that interaction for speed, accuracy, learnability, and resilience.

---

## Scope

This layer covers:
- Human motor behavior models (Fitts's Law, Steering Law)
- Affordances and signifiers
- Feedback and constraints
- Error prevention and recovery
- Interaction states (hover, focus, active, disabled, loading, etc.)
- Forms and navigation mechanics
- Direct manipulation principles

**What is not in this layer:**
- The perceptual grouping of controls → Layer 01
- Cognitive processing of feedback → Layer 02
- Motion used to communicate state changes → Layer 08

## Key Design Rule

> **Every interactive element must answer four questions:**
> 1. What can I do with this? (Affordance)
> 2. How do I operate it? (Signifier)
> 3. What happened when I did? (Feedback)
> 4. What do I do if something goes wrong? (Error recovery)
