# Layer 01 — Human Perception

**Purpose:** Explain how users visually perceive, organize, and interpret interface elements before any cognitive processing occurs.

Perception is the first stage of human–interface interaction. Before a user can think about your interface, their visual system has already organized it into groups, separated figure from background, and assigned relative importance. Understanding how this happens allows designers to create interfaces that feel natural, reduce scanning effort, and direct attention correctly.

---

## Scope

This layer covers:
- Gestalt perceptual principles (grouping, organization, completion)
- Visual hierarchy and salience
- Figure–ground separation
- Contrast and attention

**What is not in this layer:**
- Cognitive processing of perceived elements → Layer 02
- Attentional capture and scanning patterns → Layer 04
- Visual feedback from interactions → Layer 05

## Key Insight for AI Agents

**Perception happens before cognition.**

An AI generating UI must first ensure that the visual organization communicates grouping, hierarchy, and relationships correctly — before optimizing for cognitive clarity, interaction, or aesthetics.

Gestalt principles describe what users *see automatically*. They are not optional styling suggestions. They define the pre-cognitive structure that every other design layer builds upon.
