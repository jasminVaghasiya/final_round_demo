## Notes on Standard Versions

When citing WCAG requirements, always specify the version and success criterion number:
- "WCAG 2.1 SC 1.4.3" (for criteria introduced in WCAG 2.1)
- "WCAG 2.2 SC 2.4.11" (for criteria introduced in WCAG 2.2)
- "WCAG 2.5.8 (WCAG 2.2)" is an acceptable shorthand when version is parenthetically noted

Do not cite WCAG without specifying the version. Criteria changed between versions.
